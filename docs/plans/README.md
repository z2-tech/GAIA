# Plans

Planos de implementação aprovados, escritos para serem lidos por qualquer agente que
pegue o trabalho no meio.

Cada plano é um arquivo `<slug>.md` com, no mínimo:

- **Status** e data da última atualização
- **Contexto**: as cards de origem e o estado do repositório quando o plano foi escrito
- **Decisões tomadas** e a justificativa de cada uma
- **Fases** com arquivos afetados
- **Definição de pronto**
- **Fora de escopo** e pendências abertas

Um plano permanece no diretório depois de concluído — ele é o registro do *porquê*,
que o git log sozinho não carrega. Marque o `Status` como `Concluído` em vez de apagar.

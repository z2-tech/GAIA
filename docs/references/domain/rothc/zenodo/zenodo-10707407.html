It uses a monthly time step to calculate total organic carbon (t ha -1), microbial biomass carbon (t ha -1) and Δ14C (from which the equivalent radiocarbon age of the soil can be calculated).   Development history The first version of RothC created by David Jenkinson and James Rayner in 1977 (Jenkinson and Rayner, 1977). In 1987 an updated version was published, see Jenkinson et al. (1987).  This version included the prediction of the radiocarbon age of the soil, the pools POM (physically stabilized organic matter) and COM (chemically stabilized organic matter) were replaced with Hum (humified organic matter) and IOM (inert organic matter), and the microbial biomass pool was split into BioA (autochthonous biomass) and BioZ (zymogenous biomass). In 1990, the two biomass pools were combined into a single pool (Jenkinson, 1990) this version is the standard version of the model, that this code refers to. Other published developments of the model include: Farina et al. (2013) modified the soil water dynamics for semi-arid regions. Giongo et al. (2020) created a daily version and modified the soil water dynamics, for Caatinga shrublands, in the semiarid region, North-East Brazil.   Description of files included RothC_description.docx This file contains the description of the model.   RothC.for This file contains the RothC code, it can be used as a standalone subroutine or used with shell.for to create an exe file. Details of the inputs required, pools modelled, and units are in the code.   Shell.for This file is intended as an example of how to: 1)      read in the input data 2)      call the subroutine 3)      created monthly and yearly outputs The file can be used to create a standalone exe, or you can replace it with your own code to call and run RothC. Details of the inputs required, pools modelled, and units are in the code.   RothC_input.dat This file contains input variables for the model.    At the start of the file values for clay (%), soil depth (cm), inert organic matter (IOM, t C ha-1) and number of steps (nsteps) are recorded. Following that there is a table which records monthly data on  year, month, percentage of modern carbon  (%), mean air temperature (Tmp, °C), total monthly rainfall (Rain, mm), total monthly open-pan evaporation (Evap, mm), all carbon input entering the soil (from plants, roots, root exudates) (C_inp, t C ha-1), carbon input from farmyard manure (FYM, t C ha-1), plant cover (PC, 0 for no plants e.g. bare or post-harvest, 1 for plants e.g. crop or grass), and the DPM/RPM ratio (DPM_RPM) of the carbon inputs from plants.   year_results.out This file contains the yearly values of the SOC (both the pools and Total) and the delta 14-carbon. The pools are: Year Month - Always December for the yearly output DPM      - Decomposable plant material (t C ha-1) RPM      - Resistant plant material (t C ha-1) BIO         - Microbial biomass (t C ha-1) HUM     - Humified organic matter (t C ha-1) IOM       - Inert organic matter (t C ha-1) SOC        - Total soil organic carbon (t C ha-1) deltaC   - delta 14C (‰)   The total organic carbon (soil organic carbon) is equal to the sum of the 5 pools.   TOC or SOC = DRM + RPM + BIO + HUM + IOM      month_results.out This file contains the monthly inputs, rate modifying factors, SOC pools. Year Month C_Inp_t_C_ha                    - C input (t C ha-1) FYM_Inp_t_C_ha             - Farmyard manure (t C ha-1) TEMP_C                               - Air temperature (C) RM_TMP                             - Rate modifying factor for temperature (-) RAIN_mm                           - Rainfall (mm) PEVAP_mm                        - Open pan evaporation (mm) SWC_mm                            - Accumulated soil water deficit (mm) RM_Moist                           - Rate modifying factor for soil moisture (-) PC                                           - Soil plant cover (0 bare or 1 covered) RM_PC                                 - rate modifying factor for crop cover DPM_t_C_ha                      - Decomposable plant material (t C ha-1) RPM_t_C_ha                      - Resistant plant material (t C ha-1) BIO_t_C_ha                        - Microbial biomass (t C ha-1) HUM_t_C_ha                     - Humified organic matter (t C ha-1) IOM_t_C_ha                       - Inert organic matter (t C ha-1) SOC_t_C_ha                       - Total soil organic carbon (t C ha-1)   Requirements The code does not require any particular of version of Fortran, so can be compiled in both windows and Linux.   Installation/set-up A Fortran compiler is needed.   The code can be used in the following ways: 1.       The two Fortran files (RothC.for and Shell.for) can either be compiled and linked to create a standalone exe, which uses the input file (RothC_input.dat), when run, monthly (month_results.out) and yearly (year_results.out) output files are created.   2.       The file (shell.for) can be modified to read in required data in the format you have, your modified code can be compiled and linked to RothC.for. 3.       The file (RothC.for) can be called by your exiting code as a subroutine.         Example of how to run the model The file RothC_input.dat contains all the inputs data needed to run the model. The month results (month_results.out) and year results (year_results.out) files correspond to this input file as an example. The model is normally run to equilibrium using average temperature, rainfall, open pan evaporation, an average carbon input to the soil, the equilibrium run is to initialise the soil carbon pools. Once the soil carbon pools have been initialised, the model is run for the period of interest. The met data (temperature, rainfall and evaporation) can be average or actual weather data. The carbon input to the soil can be: 1) adjusted so the modelled output matches the measured data, or 2) can be estimated from yield data (Bolinder et al., 2007), or NPP data.     References   Bolinder MA, Janzen HH, Gregorich EG, Angers DA, VandenBygaart AJ. <section id="description" class="rel-mt-2 rich-input-content" aria-label="Record description">
<h2 id="description-heading" class="sr-only">Description</h2>
<div style="word-wrap: break-word;">
<p><strong><span>The Rothamsted carbon model (RothC)</span></strong></p>
<p><strong><span>Purpose</span></strong></p>
<p>Roth C models the turnover of organic carbon in non-waterlogged top-soil.<span>&nbsp; </span>It accounts for the effects of soil texture, temperature, moisture content and plant cover on the turnover process. It uses a monthly time step to calculate total organic carbon (t ha <sup>-1</sup>), microbial biomass carbon (t ha <sup>-1</sup>) and &Delta;<sup>14</sup>C (from which the equivalent radiocarbon age of the soil can be calculated).</p>
<p>&nbsp;</p>
<p><strong><span>Development history</span></strong></p>
<p>The first version of RothC created by David Jenkinson and James Rayner in 1977 <span>(Jenkinson and Rayner, 1977)</span>.</p>
<p>In 1987 an updated version was published, see <span>Jenkinson et al. (1987)</span>. <span>&nbsp;</span>This version included the prediction of the radiocarbon age of the soil, the pools POM (physically stabilized organic matter) and COM (chemically stabilized organic matter) were replaced with Hum (humified organic matter) and IOM (inert organic matter), and the microbial biomass pool was split into BioA (autochthonous biomass) and BioZ (zymogenous biomass).</p>
<p><strong>In 1990, the two biomass pools were combined into a single pool </strong><strong><span>(Jenkinson, 1990)</span></strong><strong> this version is the standard version of the model, that this code refers to.</strong></p>
<p>Other published developments of the model include:</p>
<p><span>Farina et al. (2013)</span> modified the soil water dynamics for semi-arid regions.</p>
<p><span>Giongo et al. (2020)</span> created a daily version and modified the soil water dynamics, for Caatinga shrublands, in the semiarid region, North-East Brazil.</p>
<p><span>&nbsp;</span></p>
<p><strong><span>Description of files included</span></strong></p>
<p><strong><span>RothC_description.docx</span></strong></p>
<p>This file contains the description of the model.</p>
<p><span>&nbsp;</span></p>
<p><strong><span>RothC.for</span></strong></p>
<p>This file contains the RothC code, it can be used as a standalone subroutine or used with shell.for to create an exe file. Details of the inputs required, pools modelled, and units are in the code.</p>
<p>&nbsp;</p>
<p><strong><span>Shell.for</span></strong></p>
<p>This file is intended as an example of how to:</p>
<p><span><span>1)<span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span></span></span>read in the input data</p>
<p><span><span>2)<span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span></span></span>call the subroutine</p>
<p><span><span>3)<span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span></span></span>created monthly and yearly outputs</p>
<p>The file can be used to create a standalone exe, or you can replace it with your own code to call and run RothC. Details of the inputs required, pools modelled, and units are in the code.</p>
<p>&nbsp;</p>
<p><strong><span>RothC_input.dat </span></strong></p>
<p>This file contains input variables for the model. <span>&nbsp;</span><span>&nbsp;</span></p>
<p>At the start of the file values for clay (%), soil depth (cm), inert organic matter (IOM, t C ha<sup>-1</sup>) and number of steps (nsteps) are recorded. Following that there is a table which records monthly data on <span>&nbsp;</span>year, month, percentage of modern carbon <span>&nbsp;</span>(%), mean air temperature (Tmp, &deg;C), total monthly rainfall (Rain, mm), total monthly open-pan evaporation (Evap, mm), all carbon input entering the soil (from plants, roots, root exudates) (C_inp, t C ha<sup>-1</sup>), carbon input from farmyard manure (FYM, t C ha<sup>-1</sup>), plant cover (PC, 0 for no plants e.g. bare or post-harvest, 1 for plants e.g. crop or grass), and the DPM/RPM ratio (DPM_RPM) of the carbon inputs from plants.</p>
<p>&nbsp;</p>
<p><strong><span>year_results.out</span></strong></p>
<p>This file contains the yearly values of the SOC (both the pools and Total) and the delta 14-carbon.</p>
<p>The pools are:</p>
<p><strong>Year</strong></p>
<p><strong>Month</strong> <span> </span>- Always December for the yearly output</p>
<p><strong>DPM</strong> <span>&nbsp;&nbsp;&nbsp;&nbsp; </span>- Decomposable plant material (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>RPM</strong> <span>&nbsp;&nbsp;&nbsp;&nbsp; </span>- Resistant plant material (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>BIO</strong> <span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Microbial biomass (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>HUM</strong><span>&nbsp;&nbsp;&nbsp;&nbsp; </span>- Humified organic matter (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>IOM</strong> <span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Inert organic matter (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>SOC</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Total soil organic carbon (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>deltaC</strong> <span>&nbsp; </span>- delta <sup>14</sup>C (&permil;)</p>
<p>&nbsp;</p>
<p>The total organic carbon (soil organic carbon) is equal to the sum of the 5 pools.</p>
<p>&nbsp;</p>
<p>TOC or SOC = DRM + RPM + BIO + HUM + IOM</p>
<p><span>&nbsp;&nbsp;&nbsp;&nbsp; </span></p>
<p><strong><span>month_results.out</span></strong></p>
<p>This file contains the monthly inputs, rate modifying factors, SOC pools.</p>
<p><strong>Year</strong></p>
<p><strong>Month</strong></p>
<p><strong>C_Inp_t_C_ha</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- C input (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>FYM_Inp_t_C_ha<span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span></strong>- Farmyard manure (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>TEMP_C</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Air temperature (C)</p>
<p><strong>RM_TMP</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Rate modifying factor for temperature (-)</p>
<p><strong>RAIN_mm</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Rainfall (mm)</p>
<p><strong>PEVAP_mm</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Open pan evaporation (mm)</p>
<p><strong>SWC_mm</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Accumulated soil water deficit (mm)</p>
<p><strong>RM_Moist</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Rate modifying factor for soil moisture (-)</p>
<p><strong>PC</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Soil plant cover (0 bare or 1 covered)</p>
<p><strong>RM_PC</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- rate modifying factor for crop cover</p>
<p><strong>DPM_t_C_ha</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Decomposable plant material (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>RPM_t_C_ha</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Resistant plant material (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>BIO_t_C_ha</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Microbial biomass (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>HUM_t_C_ha</strong><span>&nbsp;&nbsp;&nbsp;&nbsp; </span><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Humified organic matter (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>IOM_t_C_ha</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Inert organic matter (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>SOC_t_C_ha</strong><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span><span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>- Total soil organic carbon (t C <span>ha<sup>-1</sup></span>)</p>
<p><strong>&nbsp;</strong></p>
<p><strong><span>Requirements</span></strong></p>
<p>The code does not require any particular of version of Fortran, so can be compiled in both windows and Linux.</p>
<p>&nbsp;</p>
<p><strong><span>Installation/set-up</span></strong></p>
<p>A Fortran compiler is needed.</p>
<p>&nbsp;</p>
<p>The code can be used in the following ways:</p>
<p><span><span>1.<span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span></span></span>The two Fortran files (RothC.for and Shell.for) can either be compiled and linked to create a standalone exe, which uses the input file (RothC_input.dat), when run, monthly (month_results.out) and yearly (year_results.out) output files are created. <span>&nbsp;</span></p>
<p><span><span>2.<span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span></span></span>The file (shell.for) can be modified to read in required data in the format you have, your modified code can be compiled and linked to RothC.for.</p>
<p><span><span>3.<span>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span></span></span>The file (RothC.for) can be called by your exiting code as a subroutine. <span>&nbsp;</span><span>&nbsp;</span><span>&nbsp;</span></p>
<p>&nbsp;</p>
<p>&nbsp;</p>
<p><strong>Example of how to run the model</strong></p>
<p>The file RothC_input.dat contains all the inputs data needed to run the model. The month results (month_results.out) and year results (year_results.out) files correspond to this input file as an example.</p>
<p>The model is normally run to equilibrium using average temperature, rainfall, open pan evaporation, an average carbon input to the soil, the equilibrium run is to initialise the soil carbon pools. Once the soil carbon pools have been initialised, the model is run for the period of interest. The met data (temperature, rainfall and evaporation) can be average or actual weather data. The carbon input to the soil can be: 1) adjusted so the modelled output matches the measured data, or 2) can be estimated from yield data <span>(Bolinder et al., 2007)</span>, or NPP data. <span>&nbsp;</span></p>
<p>&nbsp;</p>
